ProDOS boot block

ProDOS and GS/OS are copyright Apple Computer, Inc.
The standard 512-byte loader is reproduced from CiderPress II 1.2.0,
DiskArc/FS/ProDOS.cs, which describes it as a boot block generated by the
GS/OS 6.0.1 ProDOS filesystem translator.

The byte sequence is unchanged. This application writes it to block 0 when
formatting a ProDOS disk image. No operating system files are included.
